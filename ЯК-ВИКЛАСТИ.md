# Як викласти «Ритм» в інтернет (GitHub Pages)

Результат: постійне посилання **https://taniatiost.github.io/rytm/**, яке працює на iPhone і Android.

## 1. Створити репозиторій (один раз)
1. На github.com угорі праворуч натисніть **+** → **New repository**.
2. **Repository name:** `rytm`
3. Оберіть **Public**. Інше не чіпайте.
4. Натисніть **Create repository**.

## 2. Завантажити файли
1. На сторінці нового репозиторію натисніть посилання **uploading an existing file**
   (або **Add file → Upload files**).
2. Відкрийте на комп'ютері папку `D:\клод код\rytm-web`.
3. Виділіть **все, що в ній є** (Ctrl+A), разом із папкою `fonts`, і перетягніть у вікно браузера.
   Файл `ЯК-ВИКЛАСТИ.md` можна не перетягувати.
4. Унизу натисніть зелену кнопку **Commit changes**.

## 3. Увімкнути сайт
1. У репозиторії відкрийте вкладку **Settings** → зліва **Pages**.
2. **Source:** `Deploy from a branch`. **Branch:** `main`, папка `/ (root)` → **Save**.
3. Зачекайте 1–2 хвилини й оновіть сторінку. Вгорі з'явиться адреса
   `https://taniatiost.github.io/rytm/`.

## 4. Встановити на iPhone
1. Відкрийте посилання саме в **Safari**.
2. Натисніть **Поділитися** (квадрат зі стрілкою ⬆️) → **На екран «Додому»** → **Додати**.
3. Відкривайте «Ритм» з іконки на екрані.
   Так дані зберігаються надійно, і застосунок відкривається на весь екран.

## Як оновлювати
Коли Claude дасть нові файли: репозиторій → **Add file → Upload files** → перетягнути нові файли
(GitHub сам замінить старі) → **Commit changes**. За хвилину оновиться в усіх.

## Важливо
- Дані кожної людини зберігаються **тільки на її телефоні**. Раз на тиждень робіть
  ⚙ → «Зберегти копію».
- Якщо видалити іконку з екрана «Додому», дані теж видаляться.
